# Hero-Varianten 1.1

Drei Richtungen für den Hero der Landingpage, jeweils als Desktop- (1440×820)
und iPhone-Fassung (390×844). Alle Farben, Radien und Schriftgrößen stammen aus
`assets/tokens.css` bzw. dem Hero-CSS in `index.html`.

| Datei | Richtung |
|---|---|
| `Main.dc.html` / `MainPhone.dc.html` | A · Ruhig weiterentwickelt |
| `DirectionB.dc.html` / `DirectionBPhone.dc.html` | B · Die Bibliothek zeigen |
| `DirectionC.dc.html` / `DirectionCPhone.dc.html` | C · Das Versprechen zuerst |
| `canvas.json` | Anordnung, Titel und Notizen der Canvas |

Bilder: aus `assets/` verkleinert (`shot-*.jpg`, `app-icon.jpg`), `badge-de.svg`
unverändert übernommen.

`booksafe-hero-varianten.html` ist die zusammengesetzte Canvas. Sie wird aus den
Dateien oben neu erzeugt und nicht von Hand bearbeitet.
